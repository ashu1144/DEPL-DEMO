DEPL Enterprise Portal - home page design (Day / Night)
=======================================================

How to view
-----------
1. Unzip this folder (right-click > Extract All). Opening the file
   from inside the zip will not load the styles and images.
2. Double-click "DEPL Portal.html". It opens in your browser;
   no internet connection or installation is needed.
3. Use a current version of Edge or Chrome.

Things to try
-------------
- The sun / moon icon (top right) switches between the day and night
  wallpaper, with a smooth fade. The page also switches by itself:
  dark mode from 5:30 PM to 6:00 AM, light mode the rest of the day.
- Watch the network arcs over the city: light travels along them.
- Hover over an app icon to see its description.
- The bell icon opens the announcements panel.
- The "SA" circle opens the account menu.

Please note
-----------
This is a design prototype. The greeting, date, time, "Recent" apps
and announcements show sample content, and the app icons do not link
anywhere yet. In the finished portal these will come from Oracle APEX.
